# Demonstration Checklist

## Before the demonstration

- [ ] Confirm the Flask application starts successfully.
- [ ] Confirm the customer onboarding page opens.
- [ ] Confirm the staff login works.
- [ ] Confirm the dashboard displays assessment results.
- [ ] Prepare fictional test information only.
- [ ] Ensure the trained model files are available.
- [ ] Keep the research proposal and thesis template accessible.
- [ ] Have the GitHub repository link available.

## Demonstration scenarios

### Scenario 1: Complete submission
- [ ] Submit a fictional record with all required information.
- [ ] Show the resulting quality assessment.
- [ ] Explain the composite score.

### Scenario 2: Missing information
- [ ] Submit a record with occupation missing.
- [ ] Show how completeness and the composite score change.

### Scenario 3: Inconsistent information
- [ ] Submit a record with an age that does not match the date of birth.
- [ ] Show the consistency assessment and resulting prediction.

## Explain the research findings

- [ ] Explain the four main data quality dimensions.
- [ ] Explain the three classification models.
- [ ] Present the model evaluation results.
- [ ] Explain the feature importance findings.
- [ ] Discuss the limitations of synthetic data and potential data leakage.

## After the demonstration

- [ ] Record the supervisor's feedback.
- [ ] Identify changes required in the implementation.
- [ ] Confirm the next thesis-writing priorities.
- [ ] Document any methodological deviations from the approved proposal.
