# Honours Research Project – Progress Summary

**Research title:** A Predictive Data Quality Scoring Model for Customer Onboarding Data in the Banking Sector

## 1. Work completed

The implementation of the research prototype has been completed to the point where its main features can be demonstrated.

A synthetic dataset containing 1,000 customer onboarding records was generated and used for the initial development and testing. The dataset includes customer information, onboarding session details and simulated behavioural measures. No real customer or bank data was used.

The data was assessed using completeness, accuracy, consistency and timeliness as the main data quality dimensions. Validity and uniqueness were also included as additional checks.

A prototype was developed with two main parts:
- A simulated customer onboarding form for submitting information.
- A staff dashboard for viewing data quality scores and the model's predictions.

The dashboard is password-protected and intended for staff and researcher access.

## 2. Model development and results

The data was prepared for model training, and classification models were tested using onboarding information, behavioural information and a combination of both.

The initial results showed that the combined data performed better than behavioural information alone. Some models achieved very high scores on the synthetic test data. However, these results need to be interpreted carefully because the data and issue labels were generated using predefined rules. The results therefore do not yet show how the models would perform on actual bank onboarding data.

The prototype and model outputs will be discussed in more detail in the thesis.

## 3. Current limitations

The current prototype has only been tested with synthetic data. It has not been tested using actual bank onboarding records or evaluated in a live banking environment.

The model results are therefore preliminary. Further testing with suitable real-world data, subject to the required approvals, would be needed before making claims about its practical performance.
