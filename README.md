# Predictive Data Quality Scoring Model

## Research Project

An Honours research project focused on developing a predictive data quality scoring model for customer onboarding data in Namibian commercial banks.

## Repository Structure

- research_documents/ – Approved research proposal, thesis template and thesis paper.
- prototype/ – Python scripts and prototype implementation.
- prototype/models/ – Trained machine learning models and preprocessing pipelines.
- data/ – Synthetic onboarding datasets used in the research.
- results/ – Model evaluation results, graphs and analysis outputs.
- notebooks/ – Jupyter notebooks.
- documentation/ – Technical and research documentation.

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- VS Code

## Data Privacy

The prototype currently uses synthetic data. No real customer data or confidential banking information should be uploaded to this repository.
